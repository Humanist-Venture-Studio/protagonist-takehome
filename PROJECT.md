# Protagonist take-home

Purpose: provide a runnable local student-assistant codebase for a CTO-level coding exercise.

This directory is an independent candidate copy. It has no production deployment target or upstream publication workflow. Preserve the core assistant, per-student isolation, durable queue, goals, memory, files, and dashboards. Use the local student simulator as the messaging surface. OpenRouter is the only external runtime service.

README.md contains the candidate assignment: a 1–2 page critique and 90-day plan, one scoped improvement, a three-hour maximum, and submission and live-session instructions. The interviewer supplies the deadline and OpenRouter test key separately. The candidate should work from this copy, not the original upstream repository.
